This repository contains the data, code, supplementary materials, and reproducibility bundles supporting the development of a theory-consistent measurement framework for global ocean-economy governance. The repository documents the derivation of governance attributes from the literature, the construction of a baseline dataset of 48 globally mandated intergovernmental organisations (IGOs), and the Python-based workflows used for retrieval, validation, thematic reduction, coding, and auditability. All outputs are designed to support transparency, traceability, and reproducibility of the analytical procedures reported in the associated investigation.
